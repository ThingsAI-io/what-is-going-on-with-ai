# Functions of a Model

## Why This Note Exists

This project is trying to build a model of the AI transformation, not just collect sources about it. That means the word "model" has to be used carefully.

A model can do more than one job. Sometimes it describes what is there. Sometimes it explains why things happen. Sometimes it helps us predict what may come next. Sometimes it is a heuristic device that makes complexity manageable. Sometimes it gives a way to interpret meaning. Sometimes it carries normative commitments. And sometimes it is critical, exposing hidden structure or power.

This note keeps those functions separate so the repository can be clear about what any given model page is trying to do.

## Main Functions

1. **Descriptive**: represents the structure of a phenomenon.
2. **Explanatory**: identifies mechanisms and causal relations.
3. **Predictive**: anticipates future states or outcomes.
4. **Heuristic**: simplifies complexity so reasoning can proceed.
5. **Interpretive**: helps make sense of meanings, categories, and narratives.
6. **Normative**: implies standards for judgment or action.
7. **Critical**: reveals assumptions, contradictions, or power relations.

## Practical Use in This Repository

When adding a model page, ask:

- What is this page trying to do?
- Which function is primary here?
- Which functions are present but secondary?
- What would count as misuse, overreach, or category error?

That keeps the model layer disciplined. A descriptive page should not pretend to be a finished theory. A heuristic page should not be mistaken for a full explanation. A normative model should make its values visible instead of hiding them inside descriptive language.

## Relevance to the Repo

The AI transformation is a moving target. The project therefore needs models that can play different roles at different levels:

- descriptive models to name recurring patterns;
- explanatory models to identify mechanisms;
- predictive models to test whether the patterns persist;
- and critical models to show who benefits, who loses, and what gets obscured.

This note is a guardrail for that work.
